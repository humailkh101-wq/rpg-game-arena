# RPG Combat Arena 2.0

A turn-based fantasy battle game made with C++ and Qt. Fight the Goblin King in a moonlit arena.

## Features
- Player vs Goblin King with health bars
- Attack, Heal, and Run Away buttons
- Battle log showing every hit
- Keyboard controls: A = Attack, H = Heal, Esc = Leave

## How to run
1. Install Qt Creator (Qt 6.12 with MinGW 64-bit).
2. Open `CMakeLists.txt` in Qt Creator.
3. Select the Desktop Qt 6.12 MinGW kit.
4. Press the green Run button.

## Built with
- C++
- Qt Widgets
- CMake
